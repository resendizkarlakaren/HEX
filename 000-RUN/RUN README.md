
# RUN – Execution Layer

RUN is the execution layer of HEX.  
Here, states are **interpreted, operated, and tested** within an experimental laboratory.

## ❦ Components

 **Notebook**: space for experimentation and recording.  
 **State-Interpreter**: applies rules and transforms states according to current conditions.  
 **Tests**: validate operations and ensure coherence in transformations.

## ❦ Principle

RUN does not define axioms or manifest states.  
Its role is to **put them into practice**, check their consistency, and reveal either failures or new possibilities.

## ❦ Role in the System

 **Λ**: axioms  
 **FLUX**: principles and patterns  
 **LIVE**: perceptive manifestation  
 **RUN**: execution, interpretation, validation  
 **Src**: technical implementation  


> _RUN is where states are tested._  
> _Every operation can expose a failure or open a new path._  
> _Validation itself becomes part of transformation._
