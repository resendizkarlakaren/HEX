

[FLUX]

├── Flux busca:
│   Reconocer y describir cómo una composición cambia
│   cuando diferencias relacionales llegan a contar dentro de ella.
│
├── Flux tiene una unidad fundamental:
│   La relación dinámica entre una composición y las diferencias
│   que pueden modificarla.
│
├── Flux opera de la siguiente manera:
│   COMPOSICIÓN → DIFERENCIA → CUENTA → TRANSFORMACIÓN → COMPOSICIÓN′
│
├── Para que una transformación cuente:
│   Un cambio de organización relacional que produce una composición
│   distinguible de la anterior:
│
│   X(T0) ≠ X(T1)
│   pero
│   X(T0) → X(T1)
│
└── Evidencias / Registros
    Una diferencia observable que pueda ser localizada, anotada,
    comparada y registrada como modificación de relaciones,
    trayectoria o comportamiento.]
